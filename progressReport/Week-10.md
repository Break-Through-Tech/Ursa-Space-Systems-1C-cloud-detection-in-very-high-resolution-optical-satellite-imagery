Agentic Coding Framework
Agents take the whole task (plan, write, run, fix), so the developer acts more like a project manager
Prompts should state goal, context, rules (what to leave alone, permissions), and a success check
Example: Claude pushing to GitHub unasked when permissions were not restricted
Workflow is explore (read only), plan (approve before code), build (watch for drift), check (verify evidence yourself)
Let agents run free only in an isolated copy, never on the main code base; watch token usage
